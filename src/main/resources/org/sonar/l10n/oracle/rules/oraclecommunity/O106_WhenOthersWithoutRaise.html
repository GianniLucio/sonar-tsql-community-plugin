Why is this an issue?

A WHEN OTHERS exception handler that does not re-raise the exception (with RAISE; or RAISE_APPLICATION_ERROR) silently swallows every unexpected error, including ones the code was not designed to handle. This hides bugs and makes production incidents very hard to diagnose.

Noncompliant Code Example

BEGIN
  do_something();
EXCEPTION
  WHEN OTHERS THEN
    NULL;
END;
/

Compliant Solution

BEGIN
  do_something();
EXCEPTION
  WHEN OTHERS THEN
    log_error(SQLCODE, SQLERRM);
    RAISE;
END;
/
