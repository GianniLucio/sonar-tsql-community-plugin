CREATE PROCEDURE/FUNCTION/PACKAGE/TRIGGER should use OR REPLACE.

A plain CREATE statement fails with ORA-00955 (name already used) if the object already exists, making deployment scripts non-idempotent. Adding OR REPLACE lets the same script be re-run safely across environments.

Noncompliant Code Example

CREATE PROCEDURE refresh_stats AS
BEGIN
    NULL;
END;
/

Compliant Solution

CREATE OR REPLACE PROCEDURE refresh_stats AS
BEGIN
    NULL;
END;
/
