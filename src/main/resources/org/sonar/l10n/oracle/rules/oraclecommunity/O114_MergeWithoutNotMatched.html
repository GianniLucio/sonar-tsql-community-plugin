MERGE should handle the WHEN NOT MATCHED case.

A MERGE statement that only defines WHEN MATCHED THEN UPDATE silently ignores every source row that has no matching target row. This is often unintentional and results in missing inserts.

Noncompliant Code Example

MERGE INTO accounts a
USING staging_accounts s ON (a.id = s.id)
WHEN MATCHED THEN UPDATE SET a.balance = s.balance;

Compliant Solution

MERGE INTO accounts a
USING staging_accounts s ON (a.id = s.id)
WHEN MATCHED THEN UPDATE SET a.balance = s.balance
WHEN NOT MATCHED THEN INSERT (id, balance) VALUES (s.id, s.balance);
