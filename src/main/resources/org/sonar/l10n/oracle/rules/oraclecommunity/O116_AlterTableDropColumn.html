Review ALTER TABLE ... DROP COLUMN statements carefully.

Dropping a column permanently removes its data and cannot be undone once the DDL is committed (Oracle DDL auto-commits). Consider marking the column UNUSED first, or confirm there is a verified backup/rollback plan before dropping it outright.

Noncompliant Code Example

ALTER TABLE employees DROP COLUMN legacy_code;

Compliant Solution

ALTER TABLE employees SET UNUSED COLUMN legacy_code;
-- drop later, once verified, during a maintenance window:
-- ALTER TABLE employees DROP UNUSED COLUMNS;
