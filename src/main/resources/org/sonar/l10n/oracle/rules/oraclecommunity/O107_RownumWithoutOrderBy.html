Why is this an issue?

ROWNUM is assigned to rows as they are produced by the execution plan, before any ORDER BY is applied. Filtering or selecting ROWNUM in a query without an explicit ORDER BY therefore returns an arbitrary, non-deterministic subset of rows that can change between executions.

Noncompliant Code Example

SELECT * FROM (SELECT id, name FROM employees) WHERE ROWNUM <= 10;

Compliant Solution

SELECT * FROM (SELECT id, name FROM employees ORDER BY id) WHERE ROWNUM <= 10;
