Procedures and functions should define an EXCEPTION handling section.

Without an EXCEPTION block, any runtime error inside the program unit propagates unhandled to the caller, with no opportunity to log context, clean up resources, or return a meaningful error to the client.

Noncompliant Code Example

CREATE OR REPLACE PROCEDURE update_balance AS
BEGIN
    UPDATE accounts SET balance = balance - 100 WHERE account_id = 1;
END;
/

Compliant Solution

CREATE OR REPLACE PROCEDURE update_balance AS
BEGIN
    UPDATE accounts SET balance = balance - 100 WHERE account_id = 1;
EXCEPTION
    WHEN OTHERS THEN
        RAISE;
END;
/
