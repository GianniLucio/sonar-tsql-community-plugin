CREATE SEQUENCE should explicitly specify CACHE/NOCACHE and ORDER/NOORDER.

Leaving these clauses to the database default makes sequence behavior implicit and environment-dependent. Cached sequence values are lost on instance shutdown or in RAC environments, producing gaps; and unordered sequences do not guarantee monotonically increasing values across RAC instances. Specify both clauses explicitly so the intended behavior is documented and predictable.

Noncompliant Code Example

CREATE SEQUENCE order_seq;

Compliant Solution

CREATE SEQUENCE order_seq CACHE 20 ORDER;
