Avoid issuing ROLLBACK inside a procedure, function, package, or trigger body.

Program units should not control transaction boundaries that belong to the caller. A ROLLBACK issued deep inside reusable code silently discards work the caller did not expect to lose, and issuing it inside a trigger raises ORA-04092 (cannot COMMIT/ROLLBACK in a trigger).

Noncompliant Code Example

CREATE OR REPLACE PROCEDURE update_balance AS
BEGIN
    UPDATE accounts SET balance = balance - 100 WHERE account_id = 1;
    ROLLBACK;
END;
/

Compliant Solution

CREATE OR REPLACE PROCEDURE update_balance AS
BEGIN
    UPDATE accounts SET balance = balance - 100 WHERE account_id = 1;
END;
/
