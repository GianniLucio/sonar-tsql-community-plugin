CONNECT BY should reference PRIOR.

A hierarchical query without a PRIOR comparison in its CONNECT BY clause has no defined parent/child relationship. Depending on the data this can raise ORA-01436: CONNECT BY loop in user data or silently produce an unbounded, incorrect result set.

Noncompliant Code Example

SELECT id FROM employees CONNECT BY id = manager_id;

Compliant Solution

SELECT id FROM employees CONNECT BY PRIOR id = manager_id;
