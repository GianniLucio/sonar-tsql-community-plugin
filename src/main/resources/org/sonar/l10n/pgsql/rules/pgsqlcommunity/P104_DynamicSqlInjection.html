Building dynamic SQL by concatenating strings is vulnerable to SQL injection attacks.

  • Security Risk (CWE-89): Attacker can inject malicious SQL code
  • OWASP A1: Injection is listed as a top security vulnerability
  • Data Loss: Unauthorized database access or modification

Recommendation: Use parameterized queries (prepared statements) instead.

Noncompliant Code:

EXECUTE 'SELECT * FROM users WHERE id = ' || user_id;
query = "SELECT * FROM users WHERE name = '" + name + "'";

Compliant Code:

PREPARE stmt AS SELECT * FROM users WHERE id = $1;
EXECUTE stmt(user_id);

-- Or using dynamic SQL safely:
EXECUTE format('SELECT * FROM users WHERE id = %L', user_id);
