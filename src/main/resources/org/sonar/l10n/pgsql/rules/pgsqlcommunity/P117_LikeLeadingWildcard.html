LIKE/ILIKE patterns should not start with a wildcard (% or _).

A leading wildcard prevents a standard B-tree index from being used to satisfy the predicate, forcing a full table scan. Consider a trigram index (pg_trgm) or a full-text search index if suffix/substring matching is required.

Noncompliant Code Example

SELECT id FROM users WHERE name LIKE '%foo';

Compliant Solution

SELECT id FROM users WHERE name LIKE 'foo%';
