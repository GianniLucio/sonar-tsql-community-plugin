Using SELECT * returns all columns in a table, which can lead to several problems:

  • Performance: Unnecessary columns are fetched, increasing I/O and network overhead
  • Maintainability: Adding columns to the table changes query behavior unexpectedly
  • Security: Sensitive columns may be unintentionally exposed

Recommendation: Always explicitly specify the column names you need.

Noncompliant Code:

SELECT * FROM users;
SELECT u.* FROM users u;

Compliant Code:

SELECT id, name, email FROM users;
SELECT u.id, u.name, u.email FROM users u;
