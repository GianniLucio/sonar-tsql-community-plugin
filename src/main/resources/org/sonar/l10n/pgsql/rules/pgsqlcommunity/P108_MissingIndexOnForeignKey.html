Foreign key columns should have indexes for optimal query performance.

  • Performance: Indexes speed up JOIN operations and foreign key lookups
  • Referential Integrity: Faster constraint validation
  • Best Practice: Standard database optimization technique

Recommendation: Create indexes on columns that are part of foreign key constraints.

Noncompliant Code:

CREATE TABLE orders (
  id SERIAL PRIMARY KEY,
  user_id INT REFERENCES users(id),
  amount DECIMAL
);
-- No index on user_id

Compliant Code:

CREATE TABLE orders (
  id SERIAL PRIMARY KEY,
  user_id INT REFERENCES users(id),
  amount DECIMAL
);
CREATE INDEX idx_orders_user_id ON orders(user_id);
