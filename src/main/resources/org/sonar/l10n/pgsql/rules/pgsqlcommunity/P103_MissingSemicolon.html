Terminating statements with a semicolon is the SQL standard and required by PostgreSQL in many contexts.

  • Clarity: Semicolons make statement boundaries explicit
  • Compatibility: Some tools and drivers expect semicolons
  • Best Practice: Recommended by SQL standards

Recommendation: Always terminate SQL statements with a semicolon.

Noncompliant Code:

SELECT id, name FROM users
INSERT INTO logs VALUES (1)

Compliant Code:

SELECT id, name FROM users;
INSERT INTO logs VALUES (1);
