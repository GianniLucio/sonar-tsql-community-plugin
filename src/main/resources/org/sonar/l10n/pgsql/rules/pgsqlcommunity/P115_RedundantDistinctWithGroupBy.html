Why is this an issue?

GROUP BY already collapses the result set to one row per distinct group. Adding DISTINCT on top of it is redundant, adds an unnecessary deduplication pass, and can mislead readers into thinking the query needs both.

Noncompliant Code Example

SELECT DISTINCT department_id, COUNT(*) FROM employees GROUP BY department_id;

Compliant Solution

SELECT department_id, COUNT(*) FROM employees GROUP BY department_id;
