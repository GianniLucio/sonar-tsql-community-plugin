Using ordinal column numbers in ORDER BY reduces query clarity and maintainability.

  • Readability: Column names are clearer than numbers
  • Maintenance: Adding/removing columns can break sorting unexpectedly
  • Best Practice: SQL best practices recommend explicit column names

Recommendation: Use explicit column names instead of ordinal numbers.

Noncompliant Code:

SELECT id, name, email FROM users ORDER BY 1, 2;
SELECT id, name FROM employees ORDER BY 3 DESC;

Compliant Code:

SELECT id, name, email FROM users ORDER BY id, name;
SELECT id, name FROM employees ORDER BY salary DESC;
