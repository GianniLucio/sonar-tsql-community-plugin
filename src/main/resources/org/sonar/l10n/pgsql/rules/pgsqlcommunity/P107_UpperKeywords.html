SQL keywords should be written in UPPERCASE for consistent style and improved readability.

  • Consistency: Uniform code style across projects
  • Readability: Keywords stand out from identifiers and values
  • Best Practice: Industry standard convention

Recommendation: Use UPPERCASE for all SQL keywords.

Noncompliant Code:

select id, name from users where active = true;
insert into logs values (1, 'test');

Compliant Code:

SELECT id, name FROM users WHERE active = TRUE;
INSERT INTO logs VALUES (1, 'test');
