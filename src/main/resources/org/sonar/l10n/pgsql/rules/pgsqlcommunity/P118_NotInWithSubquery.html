Avoid NOT IN with a subquery.

If the subquery returns even a single NULL value, the whole NOT IN condition evaluates to UNKNOWN for every row, and the outer query silently returns no rows at all. NOT EXISTS does not suffer from this NULL trap and should be preferred.

Noncompliant Code Example

SELECT id FROM users WHERE id NOT IN (SELECT user_id FROM banned);

Compliant Solution

SELECT id FROM users u WHERE NOT EXISTS (SELECT 1 FROM banned b WHERE b.user_id = u.id);
