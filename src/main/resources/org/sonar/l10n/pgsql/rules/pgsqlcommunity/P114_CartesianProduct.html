Why is this an issue?

Listing several tables in the FROM clause separated by commas, without a WHERE clause relating them, produces the full cartesian product of all rows. This is rarely intentional, can return an enormous number of rows, and usually indicates a missing join condition.

Noncompliant Code Example

SELECT o.id, c.name
FROM orders o, customers c;

Compliant Solution

SELECT o.id, c.name
FROM orders o
INNER JOIN customers c ON c.id = o.customer_id;
