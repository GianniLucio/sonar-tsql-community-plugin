Why is this an issue?

Referencing columns by ordinal numbers (e.g. ORDER BY 1, 2) harms maintainability and query readability. When columns in the SELECT list are reordered, added, or removed, the sort order changes unexpectedly without causing a syntax error.

Noncompliant Code Example

SELECT CustomerID, LastName, FirstName FROM dbo.Customers ORDER BY 2, 3;

Compliant Solution

SELECT CustomerID, LastName, FirstName FROM dbo.Customers ORDER BY LastName, FirstName;
