Avoid forcing a specific INDEX table hint.

Forcing the query optimizer to use a particular index removes its ability to adapt the execution plan when data volumes, statistics, or indexes change. What was once an optimization can silently turn into a performance regression after a schema or data change.

Noncompliant Code Example

SELECT OrderId FROM dbo.Orders WITH (INDEX(IX_Orders_CustomerId));

Compliant Solution

SELECT OrderId FROM dbo.Orders;
