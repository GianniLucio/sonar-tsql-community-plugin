Why is this an issue?

In Microsoft SQL Server, stored procedures prefixed with sp_ are designated for system procedures located in the master database.

When executing a procedure starting with sp_, SQL Server first searches the system catalog in the master database, causing extra schema locks and cache misses before searching the user database.

Noncompliant Code Example

CREATE PROCEDURE dbo.sp_GetCustomerOrders
    @CustomerID INT
AS
    SELECT OrderID FROM dbo.Orders WHERE CustomerID = @CustomerID;

Compliant Solution

CREATE PROCEDURE dbo.usp_GetCustomerOrders
    @CustomerID INT
AS
    SELECT OrderID FROM dbo.Orders WHERE CustomerID = @CustomerID;
