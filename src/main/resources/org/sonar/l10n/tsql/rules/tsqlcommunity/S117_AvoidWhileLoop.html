Avoid procedural WHILE loops in T-SQL.

Iterating row-by-row (RBAR, "Row By Agonizing Row") is much slower than an equivalent set-based operation, because it prevents the query optimizer from choosing an efficient execution plan and multiplies the number of round-trips inside the engine.

Noncompliant Code Example

DECLARE @i INT = 0;
WHILE @i < 100
BEGIN
    INSERT INTO dbo.Numbers(Value) VALUES (@i);
    SET @i = @i + 1;
END;

Compliant Solution

INSERT INTO dbo.Numbers(Value)
SELECT TOP (100) ROW_NUMBER() OVER (ORDER BY (SELECT NULL)) - 1
FROM sys.all_objects;
