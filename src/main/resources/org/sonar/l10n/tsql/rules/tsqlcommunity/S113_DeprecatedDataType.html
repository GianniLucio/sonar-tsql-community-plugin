Why is this an issue?

The TEXT, NTEXT, and IMAGE data types are deprecated by Microsoft and will be removed in a future version of SQL Server. They also have significant functional limitations compared to their replacements (e.g. limited string functions, no in-row storage).

Noncompliant Code Example

CREATE TABLE dbo.Articles (
    ArticleID INT PRIMARY KEY,
    Body TEXT
);

Compliant Solution

CREATE TABLE dbo.Articles (
    ArticleID INT PRIMARY KEY,
    Body VARCHAR(MAX)
);
