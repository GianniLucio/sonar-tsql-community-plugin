Why is this an issue?

Executing dynamic SQL queries constructed through string concatenation exposes the database to critical SQL Injection (CWE-89 / OWASP A1) vulnerabilities.

Noncompliant Code Example

DECLARE @sql NVARCHAR(1000);
SET @sql = 'SELECT * FROM dbo.Users WHERE UserName = ''' + @UserName + '''';
EXEC(@sql);

Compliant Solution

DECLARE @sql NVARCHAR(1000) = N'SELECT UserID, UserName, Email FROM dbo.Users WHERE UserName = @pUser;';
EXEC sp_executesql @sql, N'@pUser NVARCHAR(100)', @pUser = @UserName;
