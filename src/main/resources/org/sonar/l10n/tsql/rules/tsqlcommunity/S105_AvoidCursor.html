Why is this an issue?

Procedural cursors (CURSOR) force row-by-row processing (RBAR) inside the database engine, bypassing set-based query optimization and consuming extensive memory and tempdb resources.

Noncompliant Code Example

DECLARE order_cursor CURSOR FOR
SELECT OrderID FROM dbo.Orders;

Compliant Solution

Rewrite iterative logic using set-based operations (JOIN, CTE, Window Functions, or bulk DML).
